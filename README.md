# PerpetualMiner — suporte

Página de suporte do complemento **PerpetualMiner · Cartões de frases com IA** para o Anki.

Aqui não há código. Este espaço serve só para dúvidas, relatos de erro e sugestões sobre o complemento.

## Como pedir ajuda

Abra uma issue em https://github.com/vinicius928e8r84/perpetualminer-suporte/issues e conte:

- o que você tentou fazer;
- o que aconteceu no lugar;
- a versão do Anki e do sistema (Windows, Mac ou Linux).

Não cole chaves de API, senhas nem o conteúdo da sua coleção do Anki.
